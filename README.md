# Couch Room

A minimal personal site with two pages:

- `index.html` — “Hello, World!”
- `devlog/index.html` — the devlog

The site uses plain HTML and CSS, so GitHub Pages can publish it directly from
the repository root without a build step.

To preview it locally, run a static file server from this directory. For
example:

```sh
python -m http.server 8000
```
